# paper_code

Code for figures, GRN baselines, dynamics, evaluation, and network feature extraction. Every code file has an individual sibling README generated from its source.

Source files from `plots/` and `upstream/`, plus regression tests in `tests/`, are included. Datasets, checkpoints, result tables, figures, manuscript files, metadata, archives, caches, and backup copies are excluded. Scripts reference external inputs and server paths that must be configured. Dependencies are not pinned. Private-data analyses and manuscript figures have not been regenerated by these tests.

Run CPU validation with `python -m unittest discover -s tests -v`. Tests cover checkpoint loading, balanced direction accuracy, TF-target reference density, Fig. 6c source selection, EMA/input preprocessing, cache validation and finite pseudotime handling. External model/data dependencies are replaced with explicit test fixtures where needed; passing these tests does not substitute for rerunning real pretrained analyses.
