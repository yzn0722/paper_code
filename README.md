# paper_code

Code for figures, GRN baselines, dynamics, evaluation, and network feature extraction. Every code file has an individual sibling README generated from its source.

Only source files from `plots/` and `upstream/` are included. Datasets, checkpoints, result tables, figures, manuscript files, metadata, archives, caches, and backup copies are excluded. Scripts reference external inputs and server paths that must be configured. Dependencies are not pinned. No computations or figures were rerun during packaging.
